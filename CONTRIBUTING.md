# Contribuir

Las mejoras son bienvenidas.

1. Crea una rama a partir de `main`.
2. Mantén la lógica de dominio separada de la interfaz.
3. Trabaja las duraciones internamente en minutos.
4. Añade o actualiza pruebas cuando cambies cálculo de horas, solapamientos o reglas de conflicto.
5. Ejecuta `npm test` antes de proponer cambios.
6. Evita introducir dependencias externas salvo que aporten una ventaja clara y justificable.

Para cambios de interfaz, conserva accesibilidad por teclado, contraste suficiente y uso cómodo en escritorio/tablet.
